## Projects
 
**[AI Protect and Governance](https://github.com/WyattMcCoy/AI-Protect-and-Governance)** · Governance drafts, Python prototype
A draft framework for documenting, reviewing, and preserving evidence about changes to advanced AI systems, plus DCH-01, a research prototype. No real AI model has been run in DCH-01, and the README explains what the work can't show.
 
**[Digital Behavioral Baseline Tool](https://github.com/WyattMcCoy/Behavior-Baseline-Analysis-)** · Python
Anomaly detection on synthetic login session data. The tool learns what normal activity looks like for each user and flags the most unusual 3.75% of sessions for an analyst to review. The test data includes role-based activity, people returning from leave, remote and hybrid workers, and users who log in at odd hours, so the model has to work through realistic noise. Users with no history go to manual review instead of being scored.
 
**[SF Vehicle Break-In Analysis](https://github.com/WyattMcCoy/SF-vehicle-breakin-analysis)** · Python, QGIS
Hot spot and trend analysis of San Francisco car break-ins using SFPD incident data from DataSF. The findings are written up as a two-page intelligence bulletin. [Read the bulletin](https://github.com/WyattMcCoy/SF-vehicle-breakin-analysis/blob/main/SF_Vehicle_Break-In_Bulletin.pdf)
 
**[Juvenile Recidivism Predictor Study](https://github.com/WyattMcCoy/Recidivism-Study)** · Python
Logistic regression on synthetic data, looking at how different interventions relate to reoffending among justice-involved adolescent boys.
