# Hi, I'm Travis

I spent eight years in residential care for court-placed youth, first running group homes for adolescent boys and then as a residential counselor. Now I'm finishing a BA in Psychology with a minor in Criminal Justice Studies at San Francisco State (2027) and learning to analyze crime and security data.

I'm working toward a career as a criminal intelligence analyst, with a growing focus on AI security.

## Projects

**[SF Vehicle Break-In Analysis](LINK)** · Python, QGIS
Hot spot and trend analysis of San Francisco car break-ins using SFPD incident data from DataSF. The findings are written up as a two-page intelligence bulletin. [Read the bulletin](LINK)

**[Digital Behavioral Baseline Tool](LINK)** · Python
Anomaly detection on synthetic login session data. The tool learns what normal activity looks like for each user and flags the most unusual 3.75% of sessions for an analyst to review. I built the test data to include role-based activity, people returning from leave, remote and hybrid workers, and users who log in at odd hours, so the model has to work through realistic noise. Users with no history go to manual review instead of being scored.

**[Juvenile Recidivism Predictor Study](LINK)** · Python
Logistic regression on synthetic data, looking at how different interventions relate to reoffending among justice-involved adolescent boys.
